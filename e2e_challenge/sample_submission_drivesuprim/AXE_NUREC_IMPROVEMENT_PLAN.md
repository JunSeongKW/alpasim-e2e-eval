## 1순위 — 자세 섭동 학습 (`only_ori_input=false`)

가장 싸고, 최대 실패 모드를 직접 겨냥합니다.

**근거**

```
offroad 8건            30클립 baseline 최대 실패 모드 (전체 15실패 중)
route ±3 m 섭동        출력 변화 정확히 0.0000 m
학습 프레임 46,509개   전부 자차가 경로 위에 정확히 있는 상태
```

경로에서 벗어난 상태에서 복귀하는 법을 배운 적이 없어, 클로즈드 루프에서 한 번
밀리면 돌아오지 않습니다.

**조치** — 런처가 강제하는 한 줄을 끄면 됩니다.

```bash
# scripts/nurec/train_staged.sh:336
"++agent.config.only_ori_input=true"      # → false
```

dataclass 기본값은 이미 `False`이고, 끄면 `ego_perturb`(회전 앙상블 3개)가
활성화됩니다.

```python
only_ori_input: bool = False
ego_perturb: EgoPerturbConfig    # n_student_rotation_ensemble = 3
```

**비용**: 재학습만. 데이터·라벨 재생성 불필요.

## 2순위 — vocabulary 재생성

큰턴이 모든 설정에서 0.00~0.12로 고정돼 있고, 랭킹으로는 손댈 수 없습니다.

**근거** — 우리 vocab을 직접 측정한 값입니다.

| 초기속도 | 후보 수 | 4초 안에 멈춤 |
|---|---|---|
| 0.0~0.5 m/s | 325 | 149 (45.8%) |
| 5~8 m/s | 694 | 17 (2.4%) |
| 8~12 m/s | 825 | 1 (0.1%) |
| **12 m/s 이상** | **1,438** | **0 (0.0%)** |

```
정지 유지 궤적       149개 (NAVSIM 795 의 1/5)
큰턴 해상도          4초에 17 m 횡변위 맞는 후보가 632개 중 5개
최고속               39.5 m/s (142 km/h) — 고속 꼬리가 예산 잠식
```

**고를 후보가 없으면 어떤 랭킹도 고르지 못합니다.** 곱 랭킹 3종이 큰턴을 전부
0점으로 만든 것이 이를 보여줍니다.

**조치**: k-means를 (속도 × 횡변위) 층화 표본으로 재생성하거나, 급정지·큰턴 궤적을
규칙 기반으로 주입합니다.

**비용**: vocab이 바뀌면 `imi` 소프트 라벨과 4,096개 후보별 PDM 점수가 전부
무효화됩니다. **라벨 재생성 + 전체 재학습.**

## 3순위 — `gt_compliance` 를 연속량으로

**근거**

```
회랑 이탈            4건
영향도               2.0 ~ 3.9%
최대영향 프레임      0%          ← 어느 프레임에서도 1위가 아님
값(평균)             -0.005      ← σ 가 1 에 붙어 로그가 0 으로 눌림
```

"GT에서 4 m 이상 벗어났는가"의 이진 게이트라, 코너 초입에서 직진하는 후보에도
만점을 줍니다. 4 m를 넘는 시점에는 이미 `left_corridor_laterally` 실격입니다.
**경고등이 사고 후에 켜지는 구조입니다.**

**조치**: 라벨을 횡거리 연속 벌점으로 변경 (예: `exp(-d/2)` 또는 `clamp(1 - d/4)`).

**비용**: 오프라인 PDM 점수 캐시 재생성 + 재학습.

## 4순위 — route 어텐션 예산

**근거**

```
어텐션 비중          이미지 784 토큰 vs route 20 토큰 = 2.49%
학습 프레임의 70.6%  정답이 직진 — route 가 필요한 상황 자체가 드묾
```

**조치**: config 스위치가 이미 있습니다.

```python
route_separate_attention: bool = False   # → True
route_hidden_dim: int = 64               # 상향 여지
```

`True`면 route가 이미지와 소프트맥스를 공유하지 않아 20개 토큰이 784개에 묻히지
않습니다.

**비용**: 재학습. 설정 한 줄이라 1순위와 묶어 시험할 만합니다.

## 실험 설계 권고

### 충분히 학습한 뒤에 평가할 것

ep09(step 4,840)와 step43590의 차이가 결정적이었습니다. 같은 vocabulary·라벨·랭킹인데

```
정지 계획(종점 1 m 미만)   0프레임  →  37프레임
계획 종점 중앙값           38.87 m  →   6.41 m
```

미성숙 체크포인트로 수행한 랭킹 실험(rankv2/rankv3/rankprod)은 전부 무의미했습니다.
가중치 탐색은 수렴 이후에만 의미가 있습니다.

### 오픈루프 지표를 믿지 말 것

학습 인계본의 val 13,729 프레임 측정에서 곱 랭킹이 우수했습니다
(정지 상위256 위험 4.6% → 1.5%). 그런데 클로즈드 루프에서는 **offroad 8 → 13건**으로
악화됐습니다. 같은 문서 7장의 경고가 그대로 현실화된 것입니다 — *"오픈루프는 매
프레임 자차를 기록 위치로 되돌리므로 클로즈드 루프 누적 실패가 잡히지 않는다."*

### 클립 유형을 나눠 볼 것

30클립을 GT 특성으로 분류하면 실패 구조가 드러납니다(두 그룹은 겹치지 않음).

```
정지 6개    정지 프레임 >= 30%          모든 설정에서 0.5000 으로 동일
큰턴 10개   4초 창 헤딩 변화 >= 45°     모든 설정에서 최악 (0.00~0.12)
기타 14개   나머지                      il 제거 시 0.5449 → 0.0627 붕괴
```

전체 평균만 보면 이 구조가 가려집니다.

## 추천 진행 순서

| 단계 | 내용 | 재생성 필요 | 기대 |
|---|---|---|---|
| **1** | `only_ori_input=false` + `route_separate_attention=true` 재학습 | 없음 | offroad 8건 완화 |
| 2 | 30클립 검증 (`baseline` 랭킹 유지) | — | 1단계 효과 측정 |
| 3 | vocabulary 재생성 → 라벨 재생성 → 재학습 | 라벨 전체 | 큰턴 10건 |
| 4 | `gt_compliance` 연속화 → 라벨 재생성 → 재학습 | PDM 점수 | 회랑 4건 |

1단계만 데이터 재생성 없이 가능해 회전이 가장 빠릅니다. 검증은 이번과 같은
30클립·같은 분류로 하면 직접 비교됩니다.
