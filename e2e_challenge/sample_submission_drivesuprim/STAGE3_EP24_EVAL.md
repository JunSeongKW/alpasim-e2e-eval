3. **약점은 주변 차량 수가 아니라 회전입니다** — 밀도를 4배로 올려도 점수는 비슷

## 2. 이 모델이 무엇인가

번들 README 기준 3단계 커리큘럼의 최종 체크포인트. 앞서 평가한 flat ViT-S 와 아키텍처가 다릅니다.

| | flat ViT-S (ep19) | stage3 (ep24) |
|---|---|---|
| 백본 | ViT-S 단독 (파노라마 1024x256) | **ViT-S + BEVFormer** |
| BEV | 없음 | **56x56, x[0,56] y[-28,28]** |
| aux 헤드 | 꺼짐 | **BEV 분할 + DETR 객체 검출** |
| feasibility 게이트 | 꺼짐 | **켜짐** |
| 크기 | 535 MB | 763 MB |
| 자체 val 점수 | 0.9589 | 0.9708 |

번들이 주장하는 개선은 **전부 DAC** (0.9630 -> 0.9772). NC 와 EP 는 오히려 미세하게 낮습니다.

**단, README 가 스스로 밝히듯 val split 이 train log 에서 뽑혀 held-out 이 아닙니다.**
0.9708 은 일반화 추정치가 아니라 진행 게이지입니다.

예상과 일치합니다. 그 처방은 flat 의 DAC 헤드가 평균 0.962 로 포화돼 7.8% 프레임에서만

풀 포화가 없습니다.

### 4.3 2클립은 모델 탓이 아닙니다

### 5.1 실패를 가르는 것은 밀도가 아니라 회전입니다

```
통과 5개   회전각  0.6 ~  7.0°    밀도 10.4 ~ 25.4대
실패 5개   회전각 13.7 ~ 45.4°    밀도 12.8 ~ 23.9대
```

**밀도 구간은 겹치는데 회전각은 완전히 갈립니다.** 밀도 최고인 `0c9a6929`(25.4대, 순간 31대)가
만점이고, 더 한산한 `4e4a2a51`(12.8대)이 충돌로 실패합니다.

### 5.2 충돌 3건은 모두 회전 중 출발 직후

```
b44a4a44   13.7°    3.0 m 만에 충돌   완주율 0.07
4e4a2a51   18.6°   20.6 m            완주율 0.12
9e1baa2e   18.8°   59.7 m            완주율 0.27
```

장애물 최소거리가 0.00 m 로 실제 접촉입니다.

### 5.3 feasibility 게이트는 밀집+회전에서 충분하지 않습니다

stage3 의 검출 헤드 + OBB 게이트가 이번 실험의 관심사였는데 **at-fault 충돌 30%** 입니다.

게이트가 무용하다고 단정할 수는 없습니다 — 게이트를 끈 대조군이 없어 "없었으면 더 나빴을 것"을
배제하지 못합니다. 다만 이 조합에서 부족하다는 것은 분명합니다.

## 8. 남은 과제

1. **회전** — 두 클립 세트 모두 회전각이 실패를 가릅니다. flat 의 50클립 검증에서 어휘의 종점
   헤딩 분포가 `|각도| p50 1.8°, p95 56.2°` 로, 큰 회전을 표현하는 후보 자체가 부족했습니다.
   stage3 도 같은 4,096 어휘를 씁니다. **어휘 재설계가 최대 병목입니다.**
2. **밀집 상황의 충돌** — feasibility 게이트가 있음에도 at-fault 30%. 게이트 on/off 대조 실험이
   다음 단계입니다.
3. **경로 생성 실패** — 무작위 10클립 중 2개가 시뮬레이터 단계에서 거부됐습니다. 평가 표본을
   짤 때 미리 걸러내야 통계가 왜곡되지 않습니다.
