## 결론

**기본값을 이긴 조합이 없다.** 남은 손실은 후보를 고르는 방식이 아니라
**후보 자체와 모델 입력**에 있다.

---

## 1. 무엇을 바꿔봤나

```
score = σ(NC)^e · σ(DAC)^e · σ(EP)^e  +  w_imi · imi

coarse  4,096 → 256    기본 e=1/1/1, w=1.0
fine      256 →   1    기본 e=1/1/1, w=0.02
```

8축(두 단계 × NC/DAC/EP 지수 + imi 계수)을 한 축씩 움직였다.

## 2. 결과

150클립 14건 중 기준선을 넘은 것이 없다.

| 조합 | 평균 |
|---|---|
| **기준선 (전부 1.0)** | **0.6134** |
| fine DAC2.5 NC0.85 | 0.6106 |
| fine NC0.3 DAC0.3 EP2 | 0.6061 |
| fine DAC 0.5 | 0.6021 |
| coarse 포함 조합 | 0.5647~0.5795 |

상위 8건이 **0.011 폭**에 몰려 있는데 재실행 편차는 **0.023~0.030** — 구분 불가다.

60클립에서 1위였던 `fine DAC 0.5`(0.6699)는 150클립에서 8위(0.6021)로 내려갔다.
작은 표본의 노이즈였고, 60클립 결과는 폐기했다.

## 3. 확실히 나쁜 것

```
fine imi 0.0       −0.059   45°+ 구간 0.250 → 0.026 붕괴
coarse EP 2        −0.059   전체 최하위
coarse 변경 전반    150클립 6건 중 5건 하위권
```

**공통 규칙: 어느 항이든 크게 밀면 나빠진다.**

imi 를 끄면 무너지는 것은, imi 가 **사람이 실제로 어떻게 돌았는지 아는 유일한 항**이기
때문이다. coarse 를 건드리면 나빠지는 것은 그 단계가 4,096개를 걸러내는 **변별력**을
맡고 있어서다.

## 4. 실패 분석 (458클립 기준선, 평균 0.6313 / 통과 319)

### 회전각이 지배한다

| 구간 | 수 | 평균 | 통과율 | 주 실패 |
|---|---|---|---|---|
| **<20°** | 306 | **0.785** | 82% | 고르게 분포 |
| 20~45° | 63 | 0.453 | 60% | **offroad** |
| 45~60° | 18 | 0.394 | 56% | — |
| **60~90°** | 58 | **0.188** | 28% | **회랑 이탈 24건** |
| **90°+** | 13 | **0.170** | 23% | offroad |

20° 미만 대비 60° 이상이 **4.2배 낮다.** 60~90° 의 회랑 이탈 24건이 전체 58건의 41%.

### 주변 차량은 부차적이다

```
한산 <5대   0.620      보통 5~15대  0.669      밀집 15+  0.525
```

한산할 때가 보통보다 낮다 — 밀도는 주된 원인이 아니다.

### 다만 두 요인은 곱해진다

| | 한산 | 보통 | 밀집 |
|---|---|---|---|
| <20° | 0.782 | 0.801 | 0.728 |
| **45°+** | 0.301 | 0.181 | **0.027** |

큰 회전에서만 밀도가 치명적이다(−0.274 vs 직진 −0.054). 후보가 부족한데 게이트가
남은 것마저 걸러내는 것으로 보인다.

### 조합과 무관한 실패

```
회랑 이탈   6~8건 고정    예측 헤드가 없어 랭킹이 볼 수 없다
충돌        3~7건 무작위   feasibility 게이트 영역
offroad     DAC 지수에만 반응 — 진행률과 맞교환
```

## 5. 왜 개선이 없는가

랭킹은 학습 라벨(NC × DAC × EP)과 같은 형태로 이미 잘 맞춰져 있다. 남은 손실은
평가 측이 아니라 학습 측에 있다.

```
회랑 이탈 58건 (12.7%)   예측 헤드 부재
회전각 의존성 4.2배       어휘 종점 헤딩 p95 = 56° — 90° 회전 후보가 없다
```

**4초 안에 90° 를 도는 궤적이 어휘에 없으면 어떤 지수로도 고를 수 없다.**
